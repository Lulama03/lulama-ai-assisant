# TaskFlow AI

An AI-powered workplace productivity assistant with three core features:

AI Task Planner/Scheduler — add tasks with deadline and priority; generates a structured, prioritized daily/weekly plan; mark tasks complete or delete them

Smart Email Generator — generates a context-based professional email draft for a selected task, with tone adapted to the audience

AI Chatbot Interface — an interactive chat where users can ask questions like "What should I focus on today?" and get guidance based on their current tasks
