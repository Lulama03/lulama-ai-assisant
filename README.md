# AI-Productivity-Assistant

## Problem Statement
Professionals across industries spend significant time on repetitive 
tasks such as drafting emails, planning schedules, and answering 
routine questions about their workload — time that could be spent 
on higher-value work.

## Solution Overview
An AI-powered workplace productivity assistant with three core 
features:
1. **AI Task Planner/Scheduler** — add tasks with deadline and 
   priority; generates a structured, prioritized daily/weekly plan; 
   mark tasks complete or delete them
2. **Smart Email Generator** — generates a context-based professional 
   email draft for a selected task, with tone adapted to the audience
3. **AI Chatbot Interface** — an interactive chat where users can ask 
   questions like "What should I focus on today?" and get guidance 
   based on their current tasks

## Tools Used
- Lovable (AI-assisted app development and deployment)
- ChatGPT (prompt design, planning logic, content generation)

## Sample Prompts
- "Generate a structured daily plan from this task list, prioritized 
  by urgency and deadline: [task list]"
- "Write a professional email to a manager giving a status update on 
  [task], in a formal tone"
- "Based on these tasks, what should the user focus on today and why?"
